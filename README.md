# Community Notes Analysis

This repository contains the code used for the Community Notes analysis.

Data files and generated outputs are not included. The notebooks and scripts currently preserve paths from the original analysis environment; update paths before rerunning elsewhere.

## Structure

- `analysis/`: final analysis notebooks and shared analysis helpers.
- `data_generation/communitynotes_2022/`: 2022 Community Notes scoring snapshot.
- `data_generation/communitynotes_2025/`: 2025 Community Notes scoring snapshot, including the X topic-modeling code.
- `data_generation/communitynotes_twostage/`: two-stage matrix-factorization analysis code.
- `data_generation/llm_topic_modeling/`: placeholder for collaborator code that generated `notes_llm_topic.csv`.
